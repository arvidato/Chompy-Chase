## 📖 About the Game

**Chompy Chase** is a 2D side-scrolling endless runner inspired by *Jetpack Joyride*. Originally developed for **Supra**, the project was intended to be released for web browsers and integrated into a mobile application.

Players navigate through an endless running environment, avoiding obstacles, collecting power-ups, and experiencing different playable characters.

One of the main highlights of the project is its original visual design. All characters, environments, and pixel-art assets were created from scratch by me using **Aseprite**.

Although the planned mobile application integration was not completed, Chompy Chase provided an opportunity to explore game development, gameplay mechanics, original asset creation, and Unity development.

## ✨ Features

- **Endless Runner Gameplay:** Continuous side-scrolling gameplay inspired by Jetpack Joyride.
- **Multiple Characters:** Different playable characters.
- **Obstacles:** Navigate through obstacles while trying to survive.
- **Power-ups:** Collect and utilize power-ups during gameplay.
- **Original Pixel Art:** Custom-made characters, environments, and game assets created using Aseprite.
- **Unity Development:** Gameplay and mechanics implemented using C# and Unity.

## 🚀 Getting Started

To explore or run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/arvidato/Chompy-Chase.git
   ```

2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Navigate to the cloned `Chompy-Chase` folder.
5. Open the project using a compatible Unity Editor version.
6. Open the main game scene and press **Play**.
